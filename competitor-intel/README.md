# Flubberhome — Competitor Intelligence

Sistema de investigación competitiva que corre como tarea programada cada 8 horas (03:54, 11:54, 19:54, Buenos Aires).

- `SPEC.md` — instrucción completa del dueño.
- `RUNBOOK.md` — procedimiento de cada ejecución.
- `data/` — base de conocimiento acumulativa (competidores, productos, anuncios, demanda, reseñas, oportunidades, experimentos, ejecuciones) y contexto de Flubberhome.
- `reports/` — un informe por ejecución; `LATEST.md` es el último.

Independiente del monitor de Meta Ads (rama `claude/affectionate-fermat-ps9s9g`). Solo lectura: no toca campañas, tienda ni dinero.
