# Tienda FlubberHomme · ScalpCare Pro™

Tienda web de un solo producto, en español de México, lista para subir a cualquier hosting estático (Netlify, Vercel, GitHub Pages).

- Precios, variantes y fotos tomados del producto real en Shopify.
- El carrito arma el link de checkout de `flubberhomme.com/cart/<variante>:<cantidad>`, así que el pago (PayPal o tarjeta) se hace en el checkout de Shopify.
- Envío: USD 10 por debajo de USD 70, gratis desde USD 70 (igual que la configuración de la tienda).
- Pesos mexicanos: referencia con el tipo de cambio de Banxico. Para actualizarlo, edita `TC` y `TC_FECHA` al inicio del `<script>`.
- Si una foto no carga, se muestra un dibujo del aparato en su color.
